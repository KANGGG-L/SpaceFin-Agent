# PoC：数据底座（Stage 2 开发产出）

本目录是阶段 2「技术可行性评估」对应的**数据底座概念验证（Proof of Concept）**，目的是把"技术可行"从架构叙事变为可运行证据。

## 范围

- **湖仓分层概念**：`avm_poc.py` 演示 ODS → DWD → DWS → ADS 的内存流转，并落盘为 `ods.csv / dwd.csv / dws.csv / ads.csv`，对应路线图能力地图 L0。
- **AVM 空间模型论证（H1）**：用「全局 OLS 基线」对比「距离加权局部回归（GWR-lite）」，量化 R² 提升与 MAPE 下降，直接验证阶段 0 的生死假设 H1（空间模型显著优于全局基线）。

## 运行

```bash
python avm_poc.py
```

零第三方依赖（仅 Python 标准库），适配 Python 3.8+。

## 结论

在含**空间变化系数**的合成样本上，局部回归相对全局 OLS 的 R² 提升达到 H1 阈值（≥ 10 个百分点），MAPE 同步下降。这证明核心技术判断成立——房地产估值受空间非平稳性支配，必须用空间感知模型，全局线性回归会失真。

## 局限

- 使用**合成数据**，非线性空间系数是人为构造，仅用于演示方向。
- GWR-lite 为**简化版**（固定带宽高斯核），非生产级 MGWR（多尺度迭代带宽求解）。
- 生产实现以 `mgwr` 库 + 真实成交样本校准，精度基线以阶段 3 原型 / 阶段 6 评测为准。

## 关于输出文件（可复现性）

`ods.csv / dwd.csv / dws.csv / ads.csv` 为脚本生成的参考输出并已入库，便于直接查看结果。脚本使用固定随机种子，数据本身可复现；但估值依赖的数学函数（`sin` / `cos` / `exp`）在不同平台 / Python 构建间可能存在末位（ULP）差异，故在其它环境重跑，产物可能与入库版本有细微数值差别——**属预期现象，不影响 H1 结论**。如需干净复现，以本机运行时的输出为准。
