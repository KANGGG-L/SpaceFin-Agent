# SpaceFin Agent - Stage 3 MVP 端到端原型

## 是什么

`mvp_prototype.py` 是阶段 3 的开发产出，验证了 PRD 中定义的两条核心闭环流程：

- **资产质量监控闭环**（PRD 5.1）：合成数据→湖仓分层→五级分类统计→1104 G11 模板→口径一致性校验
- **LTV 爆仓预警闭环**（PRD 5.2）：AVM 估值→LTV 计算→红线比对→分层预警（正常/预警/低置信）

## 运行

```bash
python mvp_prototype.py
```

仅依赖 Python 标准库（无第三方依赖）。

## 输出

| 文件 | 说明 |
|------|------|
| `ods_loans.csv` | ODS 贴源层：贷款快照 |
| `dwd_enriched.csv` | DWD 明细层：贷款+抵押物+空间特征关联 |
| `dws_risk_class.csv` | DWS 汇总层：五级分类+高危区统计 |
| `ads_1104_g11.csv` | ADS 应用层：1104 G11 资产质量模板 |
| `ads_ltv_alerts.csv` | ADS 预警输出：LTV 超红线贷款+估值+状态 |

## 局限

- 数据为合成样本，非真实业务数据
- AVM 模型为 GWR-lite（简化带宽），非完整 MGWR 多尺度校准
- 不包含 UI/看板/驾驶舱交互（属阶段 4 设计评审范畴）
- 不包含实时反欺诈闭环（PRD 已明确排除）
