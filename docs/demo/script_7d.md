# SpaceFin-Agent 演示 · 7 天风险演进剧本（2026-08-01 ~ 2026-08-07）

> 本文档定义校招作品集演示的完整业务剧本：**稳定 → 事件 → 预警 → 处置 → 恢复**。
> 目标是让演示者能沿着一条自洽的叙事线，走完「数据底座 → 估值 → LTV → 预警 → 人工处置 → 闭环」的全链路，
> 并在驾驶舱页面上看到每一天的可见差异。
>
> - 配套验收标准见 `docs/demo/acceptance.md`。
> - 本文所有风险结构数值为**灌数目标值**，data-dev 灌数后以实测为准，按 acceptance.md 的容差判定达标。
> - 灌数统一走真实引擎：`tools/risk/main.py --date <业务日> --write-db` 每日批量回填。

---

## 1. 一句话故事线

> 8 月初，全量 5,000 笔贷款风险画像稳定运行；8 月 4 日（周二）广州核心区挂牌价异动下探，
> 数据底座 24 小时内反映到抵押物估值，广州贷款 LTV 集体上穿预警线，预警量进入高峰；
> 风控介入确认与处置后，8 月 6 日预警回落、8 月 7 日企稳收口。

| 阶段 | 业务日 | 关键词 | 一句话叙事 |
|---|---|---|---|
| 稳定 | D1 08-01（六） | 上线 | 全量 5,000 笔风险画像生成，盘面平稳 |
| 稳定 | D2 08-02（日） | 新鲜 | 爬虫新到广州房源入库，底座新鲜度刷新，分布微调 |
| 稳定 | D3 08-03（一） | 基线 | 周一例行晨会，G11 报送口径核对通过，事件前对照基线锁定 |
| 事件 | D4 08-04（二） | 异动 | 广州核心区挂牌价下探，估值下行，广州贷款 LTV 上穿 0.85 触发强预警 |
| 高峰 | D5 08-05（三） | 扩散 | 异动扩散，预警量达峰值，风控启动人工核查 |
| 处置 | D6 08-06（四） | 处置 | 风控批量确认 + 追加抵押/提前还款处置，重算后预警回落 |
| 恢复 | D7 08-07（五） | 收口 | 广州部分区域企稳，处置收尾，预警降至可控，闭环复盘 |

## 3. 广州事件设计（D4 触发）

### 3.1 事件内容

- **事件城市 = 广州（gz）**：真实爬取 1,454 条挂牌，叙事为「数据底座真实支撑事件」。
- **触发**：2026-08-04 凌晨，广州挂牌价整体下探，**幅度按行政区差异化**：

| 行政区 | 挂牌价下探幅度（unit_price_yuan 乘子） |
|---|---|
| 天河区 | **-12%** |
| 黄埔区 | **-10%** |
| 番禺区 | **-9%** |
| 增城区 | **-8%** |
| 白云区 / 海珠区 | -9% |
| 荔湾区 / 越秀区 | -8% |
| 广州整体中位 | ≈ **-10%**（落在任务要求的 -8%~-12% 区间） |

- **实现方式（data-dev）**：对 `spacefin_crawler.crawl_housing_sale` 中 `district='gz'` 的行，
  按行所属行政区对 `unit_price_yuan` 应用对应乘子（脚本 UPDATE，可复现、可回滚）。
  gz 抵押物实际命中的 DWD 键是「增城」（区级聚合，约 1 万行级）与「万科城」（小区级），
  下探后两个键的中位单价同步下降。

### 3.2 估值 → LTV → 预警 传导链（真实引擎，无需改代码）

```
crawl_housing_sale 广州挂牌价下探（-8%~-12%）
  └─▶ DWD 中位单价下降（对走 DWD 回退的抵押物直接生效）
  └─▶ AVM 重训（新版本 r12，广州城市中位/小区目标编码反映新行情）
        └─▶ gz 抵押物 market_valuation 下行（AVM 命中走 AVM，未命中回退 DWD/兜底）
              └─▶ LTV = balance / valuation 上升
                    ├─▶ LTV > 0.75 → warn 预警
                    └─▶ LTV > 0.85 → strong 预警（AC-03）
```

- 引擎优先级：AVM → DWD → true_market_price（`tools/risk/valuation.py`），全链路不用改代码。
- **重训是 D4 事件生效的关键**：AVM 模型只要存在就「命中」（未知小区回退城市中位），
  不重训则估值不变、LTV 不动。重训一次即可（约几分钟级），版本号由 `tools/avm/train.py` 自动递增。
- **低置信抑制**：`spatial_feat_missing_pct > 75` 的贷款不自动预警（AC-04），
  该批数量与合成坐标随机撒点有关，不影响广州事件传导的演示（广州受影响笔数按「非低置信」口径统计）。

## 4. 每日剧本详解

### D1 · 2026-08-01（周六）· 系统上线

- **叙事**：系统以 5,000 笔贷款规模上线，全量风险画像生成，盘面平稳。
- **动作（data-dev）**：`seed/generate_seed.py 5000` 扩样本 → 重灌业务库 → 跑引擎 `--date 2026-08-01 --write-db`。
- **关键产出**：`ads_risk_class` 出现 08-01 首行；前端驾驶舱展示 5,000 笔 KPI。

### D2 · 2026-08-02（周日）· 底座新鲜

- **叙事**：爬虫新到广州房源增量入库，数据底座新鲜度刷新；风险分布因新增挂牌微调。
- **动作**：向 `crawl_housing_sale` 追加少量真实风格广州挂牌（或不做追加、仅刷新 ETL 时间戳）→ 跑引擎 08-02。
- **关键产出**：前端「爬取规模 / 新鲜度」信任卡数值更新。

### D3 · 2026-08-03（周一）· 基线锁定

- **叙事**：周一例行晨会，G11 报送口径核对通过；08-03 为**事件前对照基线**（acceptance 的 D4 vs D3 对比基准）。
- **动作**：跑报送 `tools/reporting/main.py --date 2026-08-03`（可选）→ 跑引擎 08-03。
- **关键产出**：`ads_1104_g11` 08-03 行（如跑报送）；基线预警量 68 笔（离线）。

### D4 · 2026-08-04（周二）· 市场异动 ★ 事件日

- **叙事**：广州核心区挂牌价异动下探（天河 -12%），数据底座 24 小时内反映，AVM 重训 r12；
  广州抵押物估值下行，**约 28 笔广州贷款 LTV 上穿 0.85** 触发 strong 预警。
- **动作（data-dev）**：
  1. 广州挂牌价下探（3.1 节乘子）；
  2. `tools/avm/train.py --out-dir output/avm` 重训（新版本，预期形如 `2026-08-04-r12`）；
  3. 跑引擎 `--date 2026-08-04 --write-db`。
- **关键产出**：广州 LTV 均值显著上升；广州 strong 预警首次出现；模型版本信任卡从 r11 → r12。

### D5 · 2026-08-05（周三）· 预警高峰

- **叙事**：异动情绪扩散，更多广州贷款 LTV 上穿（含 0.75 警示线），**全量预警达峰值 168 笔**；
  实时流预警同步激增至 26 笔；风控晨会识别 strong 预警，启动人工核查（当日确认 12 笔）。
- **动作**：广州挂牌价维持低位（或对非核心区再补 1-2pp 下探）→ 跑引擎 08-05；
  前端/风控角色对部分预警做确认（写 `ads_alert_confirm`）。
- **关键产出**：`ads_ltv_alerts` 08-05 为 7 天内单日最多；预警列表出现日期聚集。

### D6 · 2026-08-06（周四）· 风控处置

- **叙事**：风控批量确认（当日 48 笔），对 26 笔实施处置：
  **追加抵押（50%）/ 提前还款（30%）/ 列入观察·展期（20%）**；
  处置后重算，广州预警回落至 46 笔。
- **动作（data-dev）**：
  1. 对部分广州高 LTV 贷款做处置落库：
     - 追加抵押：上调对应 `collateral.true_market_price`（或新增第二抵押物）；
     - 提前还款：下调 `loan.balance`（如 -20%~-30%）；
     - 观察名单：`loan.risk_class` 标记 + `ads_export_audit` 留痕；
  2. 对处置与确认动作写 `ads_alert_confirm` / `ads_export_audit`；
  3. 跑引擎 `--date 2026-08-06 --write-db`。
- **关键产出**：确认记录批量出现；处置后部分贷款 LTV 回落、当日不再进预警表；闭环漏斗「确认/处置」量 > 0。

### D7 · 2026-08-07（周五）· 企稳收口

- **叙事**：广州部分区域挂牌价企稳回升（-8% → -4%），处置收尾（累计确认 70 / 处置 44），
  全量预警回落至 86 笔（仍高于基线，但已大幅收敛），输出事件复盘，闭环完成。
- **动作（data-dev）**：对非核心区挂牌价回升乘子（+4%）→ 处置余量收口 → 跑引擎 08-07。
- **关键产出**：8/1 vs 8/7 页面对比差异明显（见第 7 节）；全链路闭环数据齐全。

## 5. 每日风险结构参数表（5000 笔 · 灌数目标值）

> 数值为 data-dev 灌数目标；验收判定按 `acceptance.md` 容差，不要求逐笔精确命中。

| 业务日 | 五级分布 正常/关注/次级/可疑/损失 | 全量 LTV 均值 | 离线预警（ads_ltv_alerts 当日） | 实时预警（ads_stream_ltv_alerts 当日） | 广州 LTV>0.75 | 广州 LTV>0.85（strong） |
|---|---|---|---|---|---|---|
| D1 08-01 | 2620 / 1050 / 410 / 350 / 570 | ≈0.51 | 62 | 6 | 20 | 8 |
| D2 08-02 | 2620 / 1050 / 410 / 350 / 570 | ≈0.51 | 65 | 7 | 20 | 8 |
| D3 08-03 | 2620 / 1050 / 410 / 350 / 570 | ≈0.51 | **68（基线）** | 7 | **21（基线）** | **8（基线）** |
| D4 08-04 | 2580 / 1060 / 430 / 360 / 570 | ≈0.53 | 118 | 16 | 55 | **28** |
| D5 08-05 | 2530 / 1070 / 450 / 380 / 570 | ≈0.55 | **168（峰值）** | **26** | 82 | **47** |
| D6 08-06 | 2565 / 1065 / 435 / 365 / 570 | ≈0.53 | 112 | 13 | 46 | 21 |
| D7 08-07 | 2595 / 1058 / 422 / 355 / 570 | ≈0.52 | 86 | 9 | 31 | 12 |

**设计说明**：

- 五级分类由引擎按 LTV 阈值实时重算（≤0.60 正常 / ≤0.75 关注 / ≤0.85 次级 / ≤1.00 可疑 / >1.00 损失），
  与 seed 的申报分类无关。每日分布总和恒为 5,000。
- **损失级（>1.00）恒定 570**：广州无接近 100% LTV 的边缘贷款，估值下探推高的是 0.70–1.00 区间，
  故变化集中在 正常↓ / 关注·次级·可疑↑，损失数量不变——这是符合业务的叙事，不要在灌数时人为造损失增长。
- **广州受影响笔数**（gz ≈ 5,000/21 ≈ 238 笔）口径：`collateral.property_addr` 以「广州市…」开头的贷款，
  按 `dws_risk_class` 中 `ltv > 阈值` 统计（排除 low_confidence 抑制笔，与引擎预警口径一致）。
- 广州 LTV 均值（关键指标）：D3 ≈ **0.50** → D4 ≈ **0.56**（+12%）→ D5 ≈ 0.58 → D6 ≈ 0.54 → D7 ≈ 0.52。

## 6. 处置节奏设计

### 6.1 处置状态流转

```
预警产生（ads_ltv_alerts, alert_level=warn/strong）
  └─▶ 人工确认（ads_alert_confirm: loan_id+alert_date+src+confirmed_by）→ 「已确认」
        └─▶ 处置落库（loan.balance 下调 / collateral 上调 / risk_class 人工标记）
              └─▶ 引擎重算（--date 当日）→ LTV 回落 → 当日不再进预警表 → 「已解除」
```

### 6.2 每日确认/处置节奏（灌数目标）

| 业务日 | 当日确认笔数 | 当日处置笔数 | 累计确认 | 累计处置 | 处置类型占比 |
|---|---|---|---|---|---|
| D1–D3 | 0 | 0 | 0 | 0 | — |
| D4 | 0 | 0 | 0 | 0 | —（事件日，系统自动预警） |
| D5 | 12 | 0 | 12 | 0 | —（启动人工核查） |
| D6 | 48 | 26 | 60 | 26 | 追加抵押 50% / 提前还款 30% / 观察·展期 20% |
| D7 | 10 | 18 | **70** | **44** | 同上 |

**收口目标**：D7 末，D4–D5 产生的 strong 预警（累计约 47~70 笔）**≥ 90% 已确认**、**≥ 60% 已处置**。

### 6.3 处置动作落库口径（data-dev）

- **追加抵押**：上调 `collateral.true_market_price`（+15%~+25%，叙事为「补充抵押物/评估复评」）
  → 引擎重算估值上升 → LTV 下降。
- **提前还款**：下调 `loan.balance`（-20%~-30%）→ LTV = balance/valuation 直接下降。
- **观察名单/展期**：`loan.risk_class` 人工改为「关注」并 `ads_export_audit` 留痕
  （引擎会按 LTV 重算覆盖，故此类主要靠确认记录 + 审计留痕体现，不依赖风险类持久化）。
- **确认动作**：写 `ads_alert_confirm`（`confirmed_by` 用演示账号如 `risk_officer`）。

## 8. 灌数技术依赖清单（data-dev 执行）

1. **扩样本**：`python3 seed/generate_seed.py 5000` → 重新生成 `sql/init/02_seed.sql` → 重灌 `spacefin` 库（保留 21 城轮序，gz ≈ 238 笔）。
2. **每日回填**：`python tools/risk/main.py --date 2026-08-0X --write-db`（X=1..7）。
3. **D4 事件**：广州挂牌价下探 SQL（3.1 乘子）→ `tools/avm/train.py --out-dir output/avm` 重训 → 引擎 08-04。
4. **D5 高峰**：挂牌价维持低位 → 引擎 08-05。
5. **D6 处置**：处置落库（6.3）→ 确认记录 → 引擎 08-06。
6. **D7 收口**：部分区挂牌价回升 +4% → 处置收尾 → 引擎 08-07。
7. **实时链路**（可选，增强演示）：起 `tools/stream/producer.py --loop` + Kafka/Flink，CDC 事件 → `ads_stream_ltv_alerts`，D4–D5 实时预警激增。
8. **报送**（可选）：`tools/reporting/main.py --date <日>` 生成 `ads_1104_g11`，D3 与 D5 各跑一次，展示「事件日口径不一致阻断」或「处置后恢复一致」。

> ⚠️ **注意**：所有灌数脚本不得改动 `tools/` 下源码；如需工具支持，先与 data-dev 对齐再另行提交。
