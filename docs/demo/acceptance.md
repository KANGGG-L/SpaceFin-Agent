# SpaceFin-Agent 演示 · 7 天剧本验收标准（acceptance.md）

> 配套剧本见 `docs/demo/script_7d.md`。本文件定义**可自动/可人工执行**的验收项，
> 分三组：**数据侧**（SQL 可验）、**前端侧**（页面可验）、**金额口径**（对账可验）。
> 每项给出：验收指令、阈值、通过标准。
>
> 判定总原则：**D4 vs D3 必须出现显著跳变，D7 vs D1 必须可见差异，全链路闭环数据必须齐全。**
> **实测对照**（2026-08-06 库内查询，供复核参考；复核结论若有出入以此为准再微调）。
>
> **⚠️ 层级差异（总额通过 ≠ 分级通过）**：本文件多数 A/B 项为**聚合（总额）口径**校验
> （如 `COUNT(*)`、五级数汇总、版本去重），只证明"批量链路跑通、总额正确"；它**不意味**
> 每一笔预警的**分级（分级失败）**都正确。实时/流式路径（`ads_stream_ltv_alerts`，
> 精简版已移除，见 A1.3 历史说明）是**可选增强**，按"总额通过"即判绿会漏掉单笔分级异常。务必区分两层：
> - **总额通过**：批处理产物（dws/ads）的数量/汇总/版本一致 → 本文件验收项判定依据；
> - **分级失败**：单笔 LTV/五级/预警档位判错（如边界阈值、高危区升档、低置信抑制）——需
>   由 AC-02 一致率抽样、AC-03/04 单笔断言与单笔回退链测试兜底，不在此文件的总额 SQL 内。
