# 导览（Overview）——从零理解 SpaceFin Agent

> **一句话定位**：SpaceFin Agent 是一个面向互联网金融机构的**房产金融风险决策支持平台**——把抵押物（房产）的自动化估值（AVM）、贷款价值比（LTV）风险预警、监管报送（1104 G11）和可视化驾驶舱串成一条可运行、可演示的完整链路。

本文件夹面向**从未接触过该仓库的读者**：不预设金融或数据工程背景，按下面的顺序读，约 30–40 分钟可建立对整个项目的准确理解。

> **项目性质**：这是一个独立研究与工程实践项目（非商用系统）。除公开渠道爬取的房产行情外，所有客户 / 抵押物 / 贷款等业务数据均为**合成数据**，不含任何真实个人金融信息——这一口径在仓库根 [README.md](../../README.md) 与各文档中保持一致。
>
> **当前为精简版（lite）**：已移除 Kafka + Flink 实时流层，预警采用 T+1 批处理推送；核心闭环（估值 → 风控 → 报送 → 前端）不受影响。

## 30 秒版本

```
真实爬取的房产行情（安居客） + 合成的信贷业务数据（客户/抵押物/贷款）
        │
        ▼
MySQL 数仓分层（ODS → DWD → DWS → ADS）
        │
        ▼
引擎层：AVM 自动估值 → 风险引擎（LTV 两档预警 / 五级分类）→ 1104 报送 → 预警推送
        │
        ▼
零依赖 Web 驾驶舱（9 个页面，RBAC 两角色）+ Airflow 每日编排 + Superset BI（可选分析副本）
```
