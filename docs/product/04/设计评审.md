## 2. 状态清单（State Inventory）

三条核心状态机，须在各页面闭合、无悬空态。

### 2.1 LTV 预警状态（PRD §5.2 / R-EVT-02 / R-UNW-01）

```
正常(LTV≤0.85) ── AVM月度重估 ──→ 比对红线
                                  │
                       LTV>0.85 ──┴─→ 预警(>0.85,特征完整) → T+1推送贷后保全
                       特征缺失>20% ──→ 低置信 → 回退人工复核(不自动推送)
                       偏差>30%且特征完整 ──→ 异常估值 → 推送人工核查
```

| 状态 | 触发 | 表现 | 回链 |
|------|------|------|------|
| 正常 | LTV ≤ 0.85 | 绿色，不入预警列表 | R-EVT-02 |
| 预警 | LTV > 0.85 且特征完整 | 红色，T+1 推送贷后保全 | AC-03 |
| 低置信 | 空间特征缺失 > 20% | 黄色，标记「低置信」，不自动推送 | R-UNW-01 / AC-04 |
| 异常估值 | 估值偏差 > 30% 且特征完整 | 橙色，标记「异常估值」，推送人工核查 | R-UNW-03 |

### 2.2 1104 报送状态（PRD §5.1 / R-UBQ-02）

```
待校验 → 校验中 → 口径一致 → 已报送
              ↘ 口径不一致 → 已阻断(推送告警至合规) → 修正后重回待校验
```

| 状态 | 触发 | 表现 | 回链 |
|------|------|------|------|
| 待校验 | 报送触发 |  awaiting | R-UBQ-02 |
| 已阻断 | 任意口径不一致 | 红色阻断 + 告警合规角色 | AC-05 / AC-08 |
| 已报送 | 一致率 100% | 绿色 | AC-08 |

### 2.3 AVM 估值状态（PRD §5.2 / R-STA-02）

```
待重估 → 计算中(月度批次) → 已完成(写入ADS)
                        ↘ 低置信(特征缺失>20%)
                        ↘ 异常估值(偏差>30%)
```

| 状态 | 触发 | 表现 | 回链 |
|------|------|------|------|
| 已完成 | 重估完成 | 写入 ADS，可参与 LTV | R-STA-02 / AC-07 |
| 低置信 | 特征缺失 > 20% | 排除自动预警，回退人工 | R-UNW-01 |
| 异常估值 | 偏差 > 30% | 推送人工核查 | R-UNW-03 |

## 3. 交互边界（Interaction Boundaries）

统一约束，跨页面一致落地（PRD §7）：

| 维度 | 规则 |
|------|------|
| 维度筛选 | 时间（日/月/季）、机构、产品类型；驾驶舱支持 |
| 下钻 | 汇总指标 → 贷款笔级明细（P2/P3） |
| 导出 | PDF（报告）/ Excel（明细）；含 PII 字段强制脱敏 + 审计日志（R-UNW-02 / AC-06） |
| 刷新频率 | BI 驾驶舱 T+1（日终批后）；LTV 预警 T+1；实时反欺诈信号仅推送不闭环 |
| 降级策略 | 空间特征缺失 / AVM 未校准 → LTV 预警回退「人工复核」标记，不自动推送处置建议 |
| 权限可见性 | 贷后保全不可见策略配置；DA 只读；风控策略经理可写惩罚项/红线阈值（PRD §7.3） |

**沙盒页（P10）特例**：启用「Critic 严格模式」时，未对接真实基准的输出须附"未校准"标记（R-OPT-01）；本期仅出框架，不实现闭环。
