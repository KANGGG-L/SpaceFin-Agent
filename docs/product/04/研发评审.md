# 阶段 4 研发评审（R&D Review）

> **定位**：阶段 4 的子交付物之一。把阶段 2 技术选型（L0–L5）与阶段 3 PRD 验收标准，细化为研发可排期的技术依赖、接口契约、数据结构与实现风险。
> **原则**：本期 MVP = L0（湖仓）+ L3（AVM）+ L2（空间）+ L5（合规）；L1（Flink CEP）仅做预警联动不闭环；L4（PerGent 沙盒）仅写需求不开发。

---

## 1. 技术依赖图（继承阶段 2 §2.2）

```
L0 湖仓底座(Hive 冷 + Doris 热 + Multi-Catalog)
   ├── L3 AVM(MGWR+GBDT 混合) ── 产出 ADS 估值 ──→ LTV 预警(R-EVT-02)
   ├── L2 空间(Sedona 分布式) ── 高危区/通勤/POI ──→ 空间惩罚项(US-01)
   └── L5 合规(倒排索引 + 1104 模板 + 特征归因)
        （L1 Flink CEP：本期仅消费 Kafka 行为流做预警联动，不回写拦截）
        （L4 PerGent：P1，仅需求，不开发）
```

**依赖顺序**：L0 先就绪 → L3/L2 挂接 → LTV 预警与空间画像可用 → L5 报送/审计收口。L1 轻量并联，不阻塞主链路。

## 2. 接口定义清单（Interface Contracts）

| # | 接口 | 方向 | 协议/形式 | 频率 | 失败处理 | 关联 |
|---|------|------|----------|------|---------|------|
| I-01 | 核心业务库 CDC | 外部→ODS | Binlog / CDC（非全量轮询） | 实时/准实时 | 断点续传 + 告警；ODS 幂等去重 | R-EVT-01 / AC-01 |
| I-02 | AVM 厂商估值 API | 平台→第三方 | REST / 按次或包年 | 月度批次（T+月） | 超时降级人工；结果标记模型版本 | R-STA-02 / AC-07 |
| I-03 | 地图/POI API | 平台→第三方 | REST（商业授权） | 空间特征计算时 | 配额耗尽降级公共层（天地图） | L2 |
| I-04 | Doris 倒排索引检索 | 内部 | SQL（USING INVERTED, chinese） | 审计查询时 | 毫秒级；无独立集群依赖 | L5 |
| I-05 | LTV/异常预警推送 | 平台→贷后系统 | API / 报表导入 | T+1 | 推送失败重试 + 站内告警 | R-EVT-02 / AC-03 |
| I-06 | 实时反欺诈信号（L1 降级） | Kafka→Flink CEP→回调 | 流（仅推送不拦截） | 秒级 | 仅信号推送，不闭环 | PRD §2.3 |

**契约待定项**：I-01 的 Binlog 采集对业务库压力须以 CDC 而非全量轮询缓解（阶段 2 L1 风险）；I-02 的真实样本量与授权见 Q2。

## 3. 数据结构（ODS–ADS Schema）

继承原型 `mvp_prototype.py` 落盘 schema（ods_loans / dwd_enriched / dws_risk_class / ads_1104_g11 / ads_ltv_alerts），生产化细化：

| 层 | 实体 | 关键字段 | 用途 | 出处 |
|----|------|---------|------|------|
| ODS | loan_snapshot | loan_id, borrower_id, balance, status, 变更时间(Binlog ts) | 贴源层，幂等去重 | R-EVT-01 |
| ODS | collateral | collateral_id, property_addr, 小区, 评估值(放款时) | 抵押物贴源 | P1 |
| DWD | enriched_loan | + 空间特征(通勤/POI/高危区标记)、空间特征缺失率 | 明细清洗关联 | L2 / R-UNW-01 |
| DWS | risk_class | loan_id, 五级分类, Roll Rate(30→60/60→90), 高危区NPL集中度 | 汇总指标 | R-STA-01 / US-02 |
| ADS | avm_valuation | loan_id, avm_value, 模型版本, 置信标记(正常/低置信/异常), 偏差% | 应用层估值 | R-STA-02 / R-UNW-03 |
| ADS | ltv_alert | loan_id, ltv, 红线(0.85), 状态(正常/预警/低置信/异常), 处置建议 | 预警输出 | R-EVT-02 / AC-03 |
| ADS | report_1104_g11 | 资产质量模板字段 + 口径一致率 | 报送 | R-UBQ-02 / AC-08 |

**口径一致性**：同一指标（NPL / Roll Rate / LTV）在 1104、BI、内部报表三出口须同源计算（AC-08 一致率 100%）。

## 4. 兼容性矩阵（Compatibility）

| 维度 | 要求 | 备注 |
|------|------|------|
| 部署环境 | 优先机构内网部署（满足个保法，D3 数据不出域） | Q1 决定；云部署需持牌通道（R-cmp-1） |
| 数据量级 | 亿级借款人坐标 × 数万多边形（Sedona 分布式） | 单机 GeoPandas 仅演示（阶段 2 L2） |
| 浏览器 | 驾驶舱兼容主流企业浏览器（Chrome/Edge） | T+1 看板，无实时渲染压力 |
| 外部系统对接 | 贷后管理系统（I-05）、AVM 厂商、地图 API | 接口契约见 §2 |
| 历史数据 | 十年全量冷数据（Hive Parquet/ORC） | L0 冷存免运维 |

## 5. 实现风险清单（Implementation Risks）

继承阶段 2 风险登记册，细化为研发可执行项：

| # | 风险 | 等级 | 缓解（研发动作） | 归属 |
|---|------|------|----------------|------|
| R-tech-1 | 技术栈复杂（Doris+Sedona+Flink+多智能体） | 高 | MVP 先 L0+L3；Flink 仅轻量联动；PoC 已证核心链路 | 阶段 4→5 |

| R-cmp-1 | 数据源合规授权不到位 | 高 | Q1/Q2 落实前不接真实数据；白名单 + 授权链路 | 阶段 4 |

| R-rev-2 | 真实数据未接入即研发 → schema 返工 | 高 | 合成数据先行开发，真实数据后切换（分环境） | 阶段 4→5 |
| **R-rd-1** | Doris 集群运维门槛 + 多源权限/血缘治理 | 中 | Multi-Catalog 免搬迁；血缘工具接入；运维手册 | 阶段 5 |
| **R-rd-2** | AVM 外推至无成交小区置信下降 | 中 | 置信标记 + 人工复核回退（R-UNW-01/03） | 阶段 5 |
