## 1. 验收环境与出口说明

- **导出出口**：S5 驾驶舱 `GET /api/alerts/export`（RBAC：admin/risk/da 可导出，服务端强制校验；见 `tools/frontend/README.md` API 一览）。
- **PII 字段**：导出 CSV 含 `customer_id`（客户号）等字段；`_handle_export` 对客户号做**最小化脱敏**——`c****{后4位}`（R-UNW-02 语义，`tools/frontend/app.py`）。
- **审计载体**：`spacefin_crawler.ads_export_audit`（`action/username/role/detail/result/ip/created_at`，`db.write_audit` 在导出后写留痕）。
- **数据前提**：预警明细来自 `ads_ltv_alerts`（离线）+ `ads_stream_ltv_alerts`（实时流，136 行），本轮导出行与预警表现状一致。

## 2. 验收方法（独立执行路径）

**步骤**（脚本 `/tmp/ac06_export_test.py`，标准库 `urllib`，不依赖浏览器）：

1. **登录**：`POST /api/login`（`da` / `da123`）→ 取会话 cookie（`spf_session`）。
2. **导出**：`GET /api/alerts/export`（带 cookie，`page_size=100000`）→ 校验 HTTP 200 与 `text/csv`。
3. **脱敏校验**：
   - 逐行提取 `customer_id` 列，用正则 `^c\*{4}\d{4}$` 判定是否脱敏格式；
   - **反向泄漏校验**：从业务库 `spacefin.loan` 取全部真实 `customer_id`（200 个），断言输出中**不出现任何明文客户号**。
4. **审计查证**：SQL 查 `ads_export_audit` 最新记录，确认存在 `action=export` 且记录 who/role/what/result/ip。
