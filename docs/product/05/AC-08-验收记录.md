## 1. 验收环境与口径说明

- **口径定义**（PRD §8）：报表口径一致率 = 不同出口（1104 / BI / 内部报表）对**同一指标**的数值一致率；AC-08 要求任意日终 = 100%。
- **验收日**：2026-08-05。指标：五级分类（正常/关注/次级/可疑/损失）的 `loan_count`、`balance_total`、`balance_pct` + 合计行。
- **两条独立路径**：
  - **路径 A（报表出口）**：`ads_1104_g11(stat_date=2026-08-05)`——`tools/reporting/main.py` 落库的 G11 报送表（1104 出口产物，含合计行）；
  - **路径 B（独立聚合）**：对 `dws_risk_class` 现状做**纯 SQL `GROUP BY risk_class`** 聚合（笔数/余额），**不经任何工具代码**——从原始明细独立复算，是口径的裁判路径。
  - **旁证路径（内部累计）**：`ads_risk_class(stat_date=2026-08-05)`（风险引擎内部汇总）+ reporting CLI 三出口校验结论。
- **容差**：与 reporting 组件一致——`balance` 差 ≤ 0.01（分位）、`balance_pct` 差 ≤ 0.0001（万分之一）、`loan_count` 严格相等。

## 2. 验收方法（独立执行路径）

**步骤**（脚本 `/tmp/ac08_check.py`，运行环境 `~/miniforge/envs/spark/bin/python`）：

1. **取路径 A**：SQL 读 `ads_1104_g11` 全部 6 行（五级 + 合计）。
2. **取路径 B**：SQL 对 `dws_risk_class` 做 `GROUP BY risk_class` 聚合（COUNT/SUM），并叠加合计行——与路径 A 无任何代码交集。
3. **逐行逐字段比对**：对每级 `loan_count`（严格相等）、`balance_total`（差 ≤0.01）、`balance_pct`（差 ≤0.0001），路径 A 对路径 B、路径 A 对内部累计各比一轮；合计行比笔数与余额。
4. **一致率** = 通过项 / 比对项总数；统计并断言 0 不一致。
5. **旁证**：`tools/reporting/main.py --date 2026-08-05` 三出口校验（出口①②③逐分级比对，`consistent=true`、exit 0，见 AC-05 记录 §3.1）。
