# 阶段 3：PRD 撰写（Product Requirements Document）

> **阶段目标**：在阶段 2（技术可行）的基础上，将优先级最高的 P0 需求（数据底座 + AVM + 空间风险推演）固化为第一版产品需求规格——明确"做什么、做成什么样、怎么验"。
> **本阶段交付物**：PRD（含功能清单、EARS 需求描述、验收标准、合规约束）；**开发产出**：核心功能原型代码（已完成，见 [poc/core-prototype/](../../poc/core-prototype/README.md)）。
> **状态**：✅ 已完成

## 1. 阶段衔接：从技术可行到产品规格

### 1.1 上游输入（来自阶段 2）

阶段 2 给出了四条推进到 PRD 的前提条件：

- **H1 已实证**：AVM PoC 验证 R² 提升 +57.4pp、MAPE 降至 10.67%，空间感知模型方向正确。PRD 可将 AVM 写入 P0 范围。
- **H5 合规通路已确认**：阶段 1 数据摸底确认三类数据在"授权+聚合+最小必要"前提下可得且合规。PRD 的数据接入需求可据此设计。
- **H3 暂未闭环**：合成仿真架构可行，但 Critic 的 ground truth 基准（真实不良率/普查数据）尚未定义。PRD 将其列为 P1，并在需求中加入"Critic 严格模式"门禁。
- **效果基线已设定**：AVM 精度@覆盖率（45% 覆盖下 MAPE ≤ 10%）、LTV 预警准确率、报表一致率 100% 等量化目标已写入阶段 2 效果基线表。PRD 的验收标准直接引用。

### 1.2 从"能做到"到"做成什么"——思考链路

```
阶段 2（技术可行）              阶段 3（本阶段）
L0 湖仓一体 路径可行    →  P0 数据底座（ODS→ADS）+ 1104 报送
L3 AVM 估值 路径可行    →  P0 AVM 月度重估 + LTV 动态预警
L2 空间计算 路径可行    →  P0 空间画像（通勤/高危区/POI）
L4 多智能体 架构可行    →  P1 沙盒推演（H3 暂未闭环，仅写需求不含开发）
L1 实时风控 路径可行    →  降级为"仅做预警联动"，不闭环（PRD Out of Scope）
```

关键边界判断：阶段 2 证明了 5 条能力各有路径，但 PRD 的职责是"砍"，不是"加"。本阶段把 L1（实时反欺诈闭环）明确排除、L4（沙盒）推迟到 P1 仅写需求——这验证了阶段 0 的"Non-goals 必写"原则在 PRD 层面的延续。

## 2. 产品范围与边界

### 2.1 MVP 一句话定位

面向城商行/农商行的**抵押物空间风险 + 资产质量监控**平台：把估值自动化（AVM）、空间维度（通勤/高危区/POI）与监管报送（1104 G11）收敛到同一湖仓底座上。

### 2.2 本版本范围（MVP = Phase 0 + Phase 1 P0）

| 模块 | 功能 | 优先级 | 来源依据 |
|------|------|--------|---------|
| 数据底座 | 多源接入（业务库/日志/空间API）+ 湖仓分层 ODS→ADS | P0 Must | 阶段 2 L0 结论 + 路线图 Phase 0 |
| 资产监控 | 五级分类迁徙矩阵 + Roll Rate + BI 驾驶舱（T+1 看板） | P0 Must | 路线图 Phase 0 + 阶段 2 结论 |
| 监管报送 | 1104 G11 模板输出 + 口径一致性校验 | P0 Must | 路线图 Phase 0 + 护栏指标 |
| 空间风控 | 空间画像（通勤/高危区/POI）+ 空间惩罚项配置 | P0 Must | 阶段 2 L2 结论 + 阶段 1 RICE P0 |
| AVM 估值 | MGWR+GBDT 混合估值 + T+月批次重估 | P0 Must | 阶段 2 L3 结论 + H1 已实证 |
| LTV 预警 | LTV 动态计算 + 两档预警比对（默认警示线 0.75 / 强预警线 0.85，可配置）+ 推送贷后保全 | P0 Must | 阶段 0 P1 痛点 + 路线图 Phase 1 |
| 合规审计 | Doris 倒排索引审计检索 + 特征归因可解释报告 | P1 Should | 阶段 2 L5 结论 + 护栏指标 |
| 沙盒推演 | PerGent 生成-批评闭环 + 策略对话沙盒（仅写需求，不含开发） | P1 Should | 阶段 2 L4 结论 + H3 待验证 |

### 2.3 明确不做（Non-goals，延续阶段 0 原则）

- **不碰核心信贷系统改造**（放款、扣款、账务——属银行核心系统范畴，非本平台职责）
- **不闭环实时反欺诈决策**（仅做预警与建议，不从本平台直接拦截交易——阶段 2 认定 L1 可行但推迟闭环）
- **不做 C 端产品**（无借款人 App、无 C 端画像页）
- **不交付多智能体仿真沙盒的完整实现**（H3 未闭环，仅写 PRD 需求，实际开发推迟至 P1 验证后）

## 4. 需求描述（EARS 原则）

> 按标准 PRD 结构，每条需求以 EARS 五类之一表述。继承阶段 2 技术结论中的约束，并补充需求清单。

### 4.1 Ubiquitous（系统始终满足的约束）

| ID | 需求 |
|----|------|
| R-UBQ-01 | 系统 shall 对所有对外输出的估值结论、预警与画像保留可追溯的数据血缘链路与模型版本号 |
| R-UBQ-02 | 系统 shall 在生成 1104 报送前自动校验口径一致性——任意不一致 shall 阻断报送并推送告警至合规角色 |

### 4.2 Event-driven（由事件触发的行为）

| ID | 需求 |
|----|------|
| R-EVT-01 | When 核心业务库发生信贷状态变更（Binlog），系统 shall 在秒级内通过 CDC 将变更同步至贴源层（ODS） |
| R-EVT-02 | When 某笔贷款的 LTV 比值超过预设警示线（默认 0.75），系统 shall 生成「警示级」预警；When LTV 比值超过强预警线（默认 0.85），系统 shall 生成「强预警级」预警——两档阈值均仅风控策略经理可配置，并 shall 在 T+1 内向贷后资产保全角色推送对应预警（含最新估值、贷款余额、空间风险标注） |

### 4.3 State-driven（在特定状态下的行为）

| ID | 需求 |
|----|------|
| R-STA-01 | While 日终批处理执行中，系统 shall 对全量贷款重算五级分类并写入 DWS 汇总层 |
| R-STA-02 | While AVM 月度重估任务执行中，系统 shall 对全量存量抵押物计算估值并写入 ADS 层 |

### 4.4 Unwanted（异常/故障处理）

| ID | 需求 |
|----|------|
| R-UNW-01 | If AVM 输入的空间特征缺失率 > 75（0–100 百分数标度，缺失率恰好 = 75 不标记），系统 shall 将该笔估值标记为「低置信」并排除出自动预警——该笔回退为人工复核 |
| R-UNW-02 | If 用户尝试导出含个人身份信息（PII）的明细数据，系统 shall 强制脱敏并写入审计日志 |
| R-UNW-03 | If AVM 估值与同小区最近成交价偏差 > 30% 且空间特征覆盖完整（偏差恰好 = 30% 不标记），系统 shall 标记为「异常估值」并推送人工核查 |

### 4.5 Optional（可选功能，P1 仅写需求）

| ID | 需求 |
|----|------|
| R-OPT-01 | Where 策略研究员启用「Critic 严格模式」，系统 shall 强制对接真实不良率/普查基准进行二次校准后方可输出 Synthetic Persona 画像——否则沙盒输出附带"未校准"标记 |
| R-OPT-02 | Where 多智能体沙盒启用，系统 shall 记录每轮 Critic 的校准结果（含对照基准、偏差量、回改次数），形成可审计的推演轨迹 |

## 5. 核心闭环流程

### 5.1 资产质量监控闭环（P0 主流程）

```
数据采集（CDC/Binlog/空间API）
  → 湖仓分层（ODS→DWD→DWS→ADS）
    → 指标计算（五级分类迁徙矩阵 / Roll Rate）
      → BI 驾驶舱（T+1 看 + 多维筛选与下钻）
        → 1104 G11 模板输出（口径一致性自动校验）
          → 策略调整（风控策略经理配置空间惩罚项）
```

### 5.2 LTV 爆仓预警闭环（P0 标志性闭环）

```
AVM 月度批次重估（MGWR+GBDT）
  → ADS 层写入估值
    → LTV = 贷款余额 / AVM 估值
      → 两档预警比对（默认警示线 0.75 / 强预警线 0.85，仅风控策略经理可配置）
        → if LTV > 0.75 → 生成「警示级」预警；if LTV > 0.85 → 升级为「强预警级」预警
          → T+1 推送对应等级预警至贷后资产保全
          → 处置：追加担保 / 启动保全 / 人工复核
```

### 5.3 策略沙盒推演（P1，仅需求不含开发）

```
定义假设（如"降低某社区消费贷利率 1%"）
  → Generator 产出初版 Synthetic Persona 画像
    → Critic 对照真实不良率/普查基准校准
      → 遇"美化断裂"强回改
        → 推演结果（含校准轨迹）→ 决策采纳/驳回
```

## 6. 验收标准（Acceptance Criteria）

> 格式：Given / When / Then。结合阶段 2 效果基线中的量化阈值。

| ID | 验收标准 | 覆盖需求 |
|----|---------|---------|
| AC-01 | Given 业务库发生信贷状态变更，When 10 秒内（秒级，实测 3s），Then 贴源层（ODS）可见该变更且无误重 | R-EVT-01 |
| AC-02 | Given 日终批处理触发，When 批处理完成，Then DWS 五级分类与手工抽样一致率 ≥ 99.9% | R-STA-01 |
| AC-03 | Given 某笔贷款 LTV 超过预警阈值，When AVM 月度重估完成，Then 贷后保全在 T+1 收到对应等级预警（含估值、余额、空间风险标注）：LTV > 0.85 为「强预警级」、0.75 < LTV ≤ 0.85 为「警示级」 | R-EVT-02 |
| AC-04 | Given 空间特征缺失率 > 75（0–100 百分数标度），When 估值完成，Then 该笔标记为「低置信」且不触发自动预警（缺失率恰好 = 75 不标记） | R-UNW-01 |
| AC-05 | Given 1104 报送触发且存在口径不一致，When 校验执行，Then 报送被阻断并推送告警至合角色 | R-UBQ-02 |
| AC-06 | Given 导出操作含 PII 字段，When 用户点击导出，Then 输出数据已脱敏且审计日志已记录 | R-UNW-02 |
| AC-07 | Given AVM 月度重估完成（模型版本 2026-08-05-r11），When 按置信分从高到低累计统计，Then 覆盖率 ≥ 45% 时 MAPE = 9.88% ≤ 10% 达标（MdAPE 6.885%，n=3618）；同时报告全量 MAPE 14.59%（MdAPE 9.48%）、基线（城市,小区）中位×面积 MAPE 20.64%、oracle 噪声下界 12.65%。置信度 = 可比案例支撑度（同城市+小区+房型、面积 ±2% 主信号，仅用训练集统计，无泄漏） | R-STA-02 |
| AC-08 | Given 报表口径一致率统计，When 任意日终, Then 一致率 = 100%（阶段 2 基线） | R-UBQ-02 |

## 7. 交互说明与边界状态

### 7.1 看板交互

- 支持维度筛选：时间（日/月/季）、机构、产品类型
- 支持下钻：从汇总指标下钻至贷款笔级明细
- 支持导出：PDF（报告）/ Excel（明细），导出含 PII 须脱敏
- 驾驶舱刷新频率：T+1（日终批处理完成后）

### 7.2 降级策略

- 空间特征严重缺失（缺失率 > 75）或 AVM 未校准时：LTV 预警（警示级/强预警级）回退为"人工复核"标记，不自动推送处置建议
- AVM 估值与最近成交价偏差 > 30%：标记异常估值，推送人工核查
- 实时反欺诈预警不在本平台闭环：仅做信号推送与建议，不执行拦截

### 7.3 权限模型（RBAC）

| 角色 | 权限 |
|------|------|
| 数据分析师(DA) | 只读：资产指标、驾驶舱、AVM 估值 |
| 风控策略经理 | 读写：配置空间惩罚项、LTV 预警阈值（警示线 0.75 / 强预警线 0.85 两档）；只读：资产指标 |
| 贷后资产保全 | 只读：LTV 预警与处置建议；不可见策略配置 |
| 数据工程师(DE) | 只读：管线运维、数据质量监控 |
| 合规官 | 只读：1104 报送、审计日志、特征归因报告 |

> 落地注：MVP 前端实现 4 角色（admin 系统管理员 / risk 风控策略经理 / da 数据分析师 / postloan 贷后资产保全）；数据工程师与合规官为后续扩展。当前合规职责由 1104 阻断告警（ads_report_alert）+ 导出审计（ads_export_audit）兜底，admin/risk 代行。

### 7.4 延迟与可用性边界

| 对象 | 容忍延迟 | 说明 |
|------|---------|------|
| BI 驾驶舱 | T+1 | 日终批处理后可见 |
| LTV 预警（警示级/强预警级） | T+1 | AVM 月度批次重估后推送 |

## 8. 数据指标与口径

继承阶段 2 效果基线，定义 PRD 层面的指标口径与数据来源：

| 指标 | 口径定义 | 计算方式 | 来源层 |
|------|---------|---------|--------|
| NPL（不良贷款率） | 不良余额 / 总贷款余额 | 按五级分类汇总 | DWS |
| Roll Rate(30→60) | 30 天逾期且在 60 天仍逾期的笔数占比 | 窗口函数追踪状态跃迁 | DWS |
| LTV（贷款价值比） | 贷款余额 / AVM 估值 | 逐笔计算 | ADS |
| AVM MAPE | 平均绝对百分比误差 | |AVM估值 - 最近成交价| / 最近成交价 | ADS + 外部成交库 |
| 报表口径一致率 | 不同出口（1104/BI/内部报表）的同一指标数值一致率 | 逐指标比对 | 跨层校验 |
