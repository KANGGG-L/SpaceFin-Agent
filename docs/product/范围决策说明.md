# 范围决策说明（Scope Decisions）

> 本文件系统记录项目交付范围的**范围决策**：每一项"移除 / 推迟 / 不做"均为刻意的取舍，而非能力缺失——在有限资源下把核心闭环做到可复现、可归因，优于铺满技术栈。

本项目交付范围 = **lite 核心闭环**：`AVM 自动估值 → LTV 两档预警 → 1104 报送 → 前端驾驶舱`，全部可运行、可演示。

| 能力 | 本项目是否交付 | 决策理由 | 什么条件下才纳入 |
| --- | --- | --- | --- |
| 实时层（Kafka / Flink） | ❌ 不交付（精简版已移除） | 单人短周期下，T+1 批处理（I-05，Airflow 排程）已满足核心预警闭环；实时联动属 V2 量级投入 | 进入生产、需要秒级事件驱动风控且有人力/集群支持时 |
| K8s 横向扩展 | ❌ 不交付 | 需真实集群与运维，非个人单机可交付；当前由「容器编排采集系统 + Redis 任务队列」覆盖横向能力 | 有真实多机集群、需弹性扩缩容的生产环境 |
| 代理池反爬爬虫 | ❌ 不交付（探索过） | 依赖真实代理配额（青果 qg 短效等），配额耗尽即不可复现，非本项目可控资源 | 有稳定代理配额 + 真实公开数据源授权时 |
| Doris / MinIO 湖仓 BI | ❌ 不交付（探索过） | 仅为分析副本 / 探索性看板，核心链（读写 MySQL）不依赖它，坏了核心照跑 | 需要历史回溯分析、即席查询的大规模 BI 时 |
| Superset 看板 | ❌ 不交付（探索过） | 固化决策视图已由前端驾驶舱承担；Superset 仅作 Doris ADS 的自由探索，核心不依赖 | 需要业务方自助拖拽分析、多数据源 BI 时 |
| AVM 自动估值 | ✅ 交付 | P0 核心价值，GBDT+空间特征，45% 覆盖 MAPE 9.88% ≤ 10% 达标（r11 历史 canonical 口径；当前已发布 r2：全量 MAPE 15.00%、45% 覆盖 9.94%，见 output/avm/avm_report.json） | —（已交付） |
| LTV 两档预警 | ✅ 交付 | 强预警线 0.85 / 警示线 0.75，可配置，T+1 推送贷后保全 | —（已交付） |
| 1104 报送（G11） | ✅ 交付 | 三出口口径一致性校验，监管合规闭环 | —（已交付） |
| 前端驾驶舱 | ✅ 交付 | 零依赖 Web 展示层，9 页覆盖资产/空间/AVM/审计/沙盒（P10 策略沙盒已并入 P6） | —（已交付） |
| 策略沙盒（LangChain） | 🟡 部分交付（框架 + 未校准标记） | 推演框架已接 LangChain；Critic 真实基准（H3）parked 为 stretch | H3 门禁达标的 V2 阶段 |
| H3 合成仿真校准 | 🔴 parked（stretch） | 校验需真实不良率 ground truth（本项目不可得） | 小规模分布对齐 PoC 达标（KS≤0.05）后才纳入 V2，否则降级为纯可视化推演工具、不声称分布保真 |
