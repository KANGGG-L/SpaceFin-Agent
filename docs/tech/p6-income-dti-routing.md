# P6 策略推演中心 · 收入类情景逐笔路由 + DTI 红线可设置

> 主要改动：`tools/risk/config.py`（行业词表）、`tools/frontend/pages/p6_policy.py`（解析/设置/压力）、`tools/frontend/static/pages/p6_policy.js`（设置控件 + 第二结果形态）。

---

## 1. 背景与目标

行业词此前不在情景解析范围内；收入/利率类情景只走示意口径（nominal 100 万/30 年月供），对任何 record 都没有定量影响。数据端借款人行业（`loan.industry`）与偿债比（`debt_ratio`）齐备——本变更把**收入下降类情景**升级为 record 级压力：情景限定（或默认全部）行业内的借款人，偿债比按 ÷(1−pct) 逐笔放大，回答「该行业内谁的偿债会被击穿」。

**边界（诚实口径）**：利率类情景逐笔月供需要执行利率/剩余期限，数据不具备——维持示意口径，不逐笔（压力测试继续拒绝）。房价类按地域路由（已实现），与行业正交。

## 2. 口径

1. **行业词表** `INDUSTRY_MAP`（risk/config.py，白名单模式同 DISTRICT_MAP）：15 门类全名 + 口语别名（互联网→信息软件业、餐饮/酒店→住宿餐饮业…）→ slug；完整名在前、别名在后，首个命中生效。
2. **DTI 红线（用户可设）**：单档，默认 0.70。存 `ads_strategy_setting`（key/value/updated_by/updated_at，DDL 走 ddl_conn）；`GET /api/policy` 的 `thresholds.dti_red_line` 下发；`POST /api/policy/setting`（admin）修改并**写审计**（action=`policy_setting`）——P6「写操作必须留痕」的第三条硬约束照用。区间校验 [0.3, 0.95]。
3. **收入逐笔传导**：受影响 record = 借款人行业匹配（无限定 → 全部）；`stressed_dti = debt_ratio / (1−pct)`；越线判定 `dti > red`（恰等于不算，与 LTV 同款）。`debt_ratio` 缺失的笔不参与重算、单列 `totals.loans_no_dti`（缺 LTV 单列同款纪律）。`debt_ratio` 为偿债比代理（无严格"月供/收入"语义），口径注释如实声明。
4. **分组维度互补推断**（与房价分支同构）：行业限定 → 按城市分组（该行业在哪些城市最危险）；仅区限定（未提行业）→ 按行业内分组（范围已小于一个区，再按区分组只会得到单行表）；仅城市限定（未提行业/区）→ 按区/镇街分组（单城内看哪个区落点最重）；全国无限定 → 按城市分组看落点（哪些城市越线增量最大）。`group_note` 回告依据。
5. **规则×收入情景（preview）**：收入不改 LTV → 命中/新增受限判定**不变**（诚实）；叙事模拟对象收窄到情景行业（`pick_profile_loan` 新增 industry 参数）；示意口径月供测算照旧并存。
6. **直方图**：DTI 五档百分比桶（0-50/50-70/70-85/85-100/100+，与 LTV 同款展示桶；越线统计用实际红线，不依赖桶边界）。

## 3. 交互

- 区情景块内（admin，随 hyp-wrap 闸门）新增一行：「收入压力红线（DTI）」百分比数字输入（30–95）+ 说明；变更即保存（POST setting），成功后 toast 明示「已留痕」。**仅在「仅情景压力运行（无作用域）+ 收入类情景」分支可见（默认隐藏）**——它唯一生效的分支就是该组合，常驻展示会让人误以为规则试算也读它（与 LTV 上限同屏两个 70 的认知冲突同源；评估结论：两者计算层面零冲突，作用于互斥路径、互不读取）。
- 仅情景（无作用域）+ 收入类情景 → 压力结果卡第二形态：KPI（受影响笔数 / 越红线笔数 before→after 带 DTI 中位数与 P90 / 越线余额）、结论行、DTI 分布直方图、分组表（表头维度随响应 `group_by`）。
- **不可定量芯片拦截**：主情景芯片全量可见后，「制造业失业率上升 3 个百分点」这类无逐笔口径的输入在仅情景运行下必触发解析失败——此时禁用失业率/利率芯片并悬停说明（`STRESS_UNSAFE_SUGGESTIONS`）。
- **错误句 i18n**：后端错误句静态化（去掉动态值回显），前端对错误消息 `t()` 整句查表（命中即译、未知句原样回落），压力相关 5 句 + DTI 2 句双语注册；解析失败文案为完整指引（支持什么 + 示例 + 什么不支持 + 利率类怎么办）。
