## 0. 两层依赖与最小可运行集

环境依赖分两层：

| 层 | 内容 | 安装位置 |
|----|------|---------|
| Conda 环境 `spark` | Python 生态（PySpark / aiohttp / selenium / pre-commit …） | conda env（虚拟，不污染系统） |
| 系统级二进制 | Hadoop / Hive / Spark / MySQL / Java | 操作系统（独立安装，不进 conda） |

**阶段性依赖（用到对应能力层时再下）：**
`PySpark`（L2/L3 真实 Sedona/AVM）、`Hadoop`/`Hive`/`Spark`（L0/L2 真实湖仓与空间计算）、`MySQL`（业务源库，Sprint 0 已用 Docker 可暂不下）、`pytest`（阶段 5 单测）、`Chrome`（Selenium 爬虫）等。

## 2. 方式一：conda 一键建环境（推荐，含现在就装的全部）

前提：本机已装 Miniconda/Anaconda（`conda` 在 PATH）。`environment.yml` 已钉版：python 3.10.18 + openjdk 17 + pyspark 4.2.0 + 爬虫/工具链。

```bash
conda env create -f environment.yml
conda activate spark
python -c "import pyspark; print('pyspark', pyspark.__version__)"   # 期望 4.2.0
java -version                                                      # 期望 17.x
```

> 若 `pyspark==4.2.0` 在 PyPI 尚未发布，把 `environment.yml` 中该行改为 `pyspark` 取最新。
> 本机尚无 conda：Linux/WSL 用 `curl -fsSL https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -o miniconda.sh && bash miniconda.sh -b -p $HOME/miniconda3`；Windows 用官网 exe（勾选 Add to PATH，用 Anaconda Prompt）。

## 3. 方式二：venv + pip（不使用 conda）

前提：本机有 Python 3.10 与 Java 17。

```bash
python3.10 -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt      # 含 pyspark 4.2.0 + 爬虫/工具链
```

## 9. 常见问题

- **`conda: command not found`**：当前 shell 没装 conda，或没 `source` 初始化脚本；按第 2 节先装 Miniconda。
- **`pyspark==4.2.0` 找不到**：PyPI 未发布时放宽版本约束为 `pyspark`。
- **PySpark 报找不到 Java**：设 `JAVA_HOME` 指向 Java 17，并确认 `java -version` 为 17.x。
- **沙箱限速无法建环境**：出网被限流时大文件（Miniconda/PySpark）下载极慢；请在有正常网络的机器执行。
