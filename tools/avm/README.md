# SpaceFin AVM 自动估值模型（S2）

替代风险引擎中「(城市, 小区) 中位单价 × 面积」的粗糙估值（`tools/risk/valuation.py`
当前口径），用机器学习模型估计单位面积价格再乘面积还原总价。

## 数据口径

- 训练集：`spacefin_crawler.crawl_housing_sale`（sale DWD），清洗后 **43,491** 行。
- 目标变量：`log(unit_price_yuan)`。选 log 单价而非直接预测总价：
  单价是"位置/品质"的直接度量，小区/邻域编码承载的正是单价水平；房价误差天然
  是乘性的，log 目标把乘性误差变成加性误差，与 MAPE 口径一致。
- 总量纲：DWD 中 `total_price_wan` 为万元，`unit_price_yuan` 为 元/㎡；
  模型输出单价（元/㎡）× 面积（㎡）= 总价（**元**），与 `market_valuation` 一致。

## 特征

1. **基础属性**：面积、log 面积、室/厅/卫数、房龄、楼层（区位/总层数/相对位置）、
   朝向编码、车位、城市码。
2. **目标编码（防泄漏）**：小区中位/均值单价、样本量、相对城市偏移；
   城市中位/均值单价。只用**训练折内**行统计（OOF），测试集映射用完整训练集
   字典；新小区回退：小区中位 → 城市中位 → 全局中位。
3. **空间特征（GWR-lite 近似）**：经纬度存在时（仅 29% 行），取训练坐标
   k=3/8/20/50 最近邻的中位单价 + 最近邻距离。训练行邻域在折内统计（不含自身）。

## 训练 / 评估命令

```bash
tools/orchestrator/.venv/bin/python tools/avm/train.py --out-dir output/avm
```

产物（`output/` 已被 .gitignore，不会入库）：

- `output/avm/model.joblib` — 模型 + 编码字典 + 特征元数据
- `output/avm/avm_report.json` — 指标、样本量、特征清单、训练时间戳、基线对照

## 指标结果（train/test = 80/20，seed=42，测试集 8,699 行，总价口径）

| 模型 | MAPE | MdAPE | R² |
|---|---|---|---|
| 基线 (城市,小区) 中位 × 面积 | **28.62%** | 15.39% | 0.677 |
| AVM (HistGradientBoosting) | **19.49%** | 12.28% | 0.810 |

MAPE 相对下降 **31.9%**。未达到规划 MAPE ≤ 10%，瓶颈与改进方向见下文。

## 预测接口

```python
from tools.avm import predict

model = predict.load_model()                      # 模型缺失返回 None，不抛异常
val = predict.estimate_total_price(               # 返回总价（元）
    model,
    city_code="gz", community="天河城",
    area_sqm=89.5, building_age=8, bedrooms=3,
)
# 可选：latitude/longitude 同时提供时启用邻域空间特征
```

- 惰性导入：模块顶层不依赖 sklearn/joblib，无模型依赖环境可安全 import。
- 信息不足（面积缺失/非法）或模型缺失 → 返回 `None`，由调用方回退。
- 城市未知 → 全局中位回退；小区未知 → 城市中位回退。

## 已知局限（为什么 MAPE 停在 ~19%）

1. **31% 的行既无小区名也无坐标**：这 31% 行没有任何位置信号，只能靠城市中位 +
   属性估计（该段 MAPE 38%，权重 31%），是模型的结构性下界——即便特征/调参
   再优化也压不下去。
2. **小区名稀疏**：community 字段是板块级标签（10,002 个取值，7,750 个仅出现
   1 次），20% 的测试行小区在训练中未见过。
3. **坐标覆盖率仅 29%**：且坐标只出现在有小区名的行上，无法补小区缺失。
4. **外市数据混入**：gz/zs/dg/zh/yf 等城市混入北京/燕郊/南昌等地房源
   （title/community 可见），单城市价格分布被污染，这 6 城贡献了最高误差段
   （dg MAPE 103%、zh 50%、yf 48%）。
5. **标签本身是挂牌价**：同小区内挂牌价离散度 MdAPE 约 6%，构成残差下界。

### 后续可行方向

- 用 title 中的楼盘名回填小区缺失（有 API 解析更佳），把 31% 的"无位置"行
  变成"有位置"行——这是冲 ≤10% 的最大杠杆。
- 清洗跨城污染数据（按坐标围栏判定真城市），把 dg/zh/yf 段误差降下来。
- 接入更多真实成交价（网签/评估价）作标签，降低挂牌价噪声。
