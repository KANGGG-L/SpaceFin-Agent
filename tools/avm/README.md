# SpaceFin AVM 自动估值模型（S2）

替代风险引擎中「(城市, 小区) 中位单价 × 面积」的粗糙估值（`tools/risk/valuation.py`
当前口径），用机器学习模型估计单位面积价格再乘面积还原总价。

## 数据口径

- 训练集：`spacefin_crawler.crawl_housing_sale`（sale DWD，44,369 行）。
- 外市清洗后 **41,483** 行（剔除 2,038 行混入的北京/燕郊/南昌/杭州湾等外市房源，
  详见「数据清洗」）。
- 目标变量：`log(unit_price_yuan)`。选 log 单价而非直接预测总价：
  单价是"位置/品质"的直接度量，小区/邻域编码承载的正是单价水平；房价误差天然
  是乘性的，log 目标把乘性误差变成加性误差，与 MAPE 口径一致。
- 总量纲：DWD 中 `total_price_wan` 为万元，`unit_price_yuan` 为 元/㎡；
  模型输出单价（元/㎡）× 面积（㎡）= 总价（**元**），与 `market_valuation` 一致。

## 数据清洗（新增，见 tools/avm/data_clean.py）

外市混入是基线最严重的污染源（dg MAPE 103%、zh 50%、yf 48%），三层可复现规则：

1. **坐标围栏**：经纬度落在「广东 21 城超围栏」（19.9-25.6N × 109.4-117.6E）之外的
   行剔除（27 行；如 lat 41.8 在黑龙江、lng 107 在广西）。
2. **文字标记**：title/community 命中北京区县/板块/楼盘名、北方市场专属词
   （集中供暖/胡同/家属院/公房）等 160+ 标记的行剔除（785 行）；带例外表防误杀
   广东同名地名（北京路=广州、北京城=中山、中梁壹号院=江门等）。
3. **城市价格上/下限**：单价超过城市真实天花板（如云浮 >1.5 万、中山 >3 万）
   或低于昂贵城市地板价（如深圳 <1.2 万、珠海 <8 千）的行剔除（1,226 行），
   清掉北京高价房源与「射阳城/阜城/燕都鑫城」这类河北江苏低价错配房源。

统计随训练写入 `output/avm/avm_report.json`（`cleaning` 字段，含分城市明细）。

**title 归一小区名**：爬虫 community 字段是整句噪音标签（10,002 个取值，
7,750 个仅出现 1 次），用「楼盘尾缀 + 描述词过滤」的保守解析器从 title
重新归一小区名（22,955 行），把同楼盘的碎片标签合并、并为无小区行回填
楼盘名。解析保守：解析不出宁可留空，绝不把「刚需小三居/大两居/望花园」
等描述词当小区名。community 缺失率由 **30.8% → 16.5%**。

## 特征

1. **基础属性**：面积、log 面积、室/厅/卫数、房龄、楼层（区位/总层数/相对位置）、
   朝向编码、车位、城市码。
2. **目标编码（防泄漏）**：小区中位/均值单价、样本量、相对城市偏移；
   城市中位/均值单价。只用**训练折内**行统计（OOF），测试集映射用完整训练集
   字典；新小区回退：小区中位 → 城市中位 → 全局中位。
3. **空间特征（GWR-lite 近似）**：经纬度存在时（约 31% 行），取训练坐标
   k=3/8/20/50 最近邻的中位单价 + 最近邻距离。训练行邻域在折内统计（不含自身）。

## 指标结果（train/test = 80/20，seed=42，测试集 8,297 行，总价口径）

| 模型 | MAPE | MdAPE | R² |
|---|---|---|---|
| 基线 (城市,小区) 中位 × 面积 | **22.57%** | 12.32% | 0.712 |
| AVM (HistGradientBoosting) | **16.63%** | 11.01% | 0.827 |

清洗前旧模型 19.49%（旧基线 28.62%）；本轮清洗 + title 归一 + 模型调参后
MAPE 相对下降 **26.3%**。仍未达到规划 MAPE ≤ 10%，剩余瓶颈见下文。

### 误差分解（测试集）

按位置信号完整度分段：

| 段 | 权重 | MAPE | MdAPE |
|---|---|---|---|
| 有小区 + 有坐标 | 30.0% | 15.88% | 10.71% |
| 有小区、无坐标 | 53.1% | 15.18% | 9.97% |
| 无小区（title 也解析不出） | 16.9% | 22.50% | 15.98% |

## 预测接口

```python
from tools.avm import predict

model = predict.load_model()                      # 模型缺失返回 None，不抛异常
val = predict.estimate_total_price(               # 返回总价（元）
    model,
    city_code="gz", community="天河城",
    area_sqm=89.5, building_age=8, bedrooms=3,
)
# 可选：latitude/longitude 同时提供时启用邻域空间特征
```

- 惰性导入：模块顶层不依赖 sklearn/joblib，无模型依赖环境可安全 import。
- 信息不足（面积缺失/非法）或模型缺失 → 返回 `None`，由调用方回退。
- 城市未知 → 全局中位回退；小区未知 → 城市中位回退。
- 特征 schema 与清洗前一致（28 维，模型 dict 结构未破坏），接口保持不变。

## 已知局限（为什么 MAPE 停在 ~16.6%）

1. **16.9% 的行既无小区名也无坐标**：title 是纯营销文本（解析不出楼盘名），
   无任何位置信号，只能靠城市中位 + 属性估计（该段 MAPE 22.5%，权重 16.9%），
   是模型的结构性下界。title 回填已把该段从 31% 压到 16.9%。
2. **广州/深圳区间价差极大且多数无坐标**：gz/sz 测试权重合计 ~6.5%，
   MAPE 34%/28%。sz 全表无坐标，gz 仅 2/3 有坐标；核心区（天河 5-10 万/㎡）
   与郊区（增城/南沙 0.8-1.5 万/㎡）同在一个城市中位里，无坐标行只能按
   城市中位估计，郊区行被系统性高估（误差尾部的主要来源）。
3. **小区名仍是稀疏标签**：归一后仍有多数小区仅出现 1 次，OOF 下这些
   小区回退城市中位，无法给新小区提供位置信号。
4. **残留外市污染**：dg/zh/zs/yf 虽经围栏/标记/价格三重清洗，仍有少量
   无标记外市房源（价格与本地重叠段）残留，这 4 城仍是最差误差段。
5. **标签本身是挂牌价**：同小区内挂牌价离散度 MdAPE 约 6%，构成残差下界。

### 后续可行方向（按杠杆排序）

- **接入网签/评估价作标签**：挂牌价噪声是残差下界，真实成交价可直接把
  MAPE 下压数个点。
- **补齐无坐标行的位置信号**：对 gz/sz 等无坐标行做批量逆地理编码，
  或按小区名映射到历史坐标，把「无位置」段转成「有位置」段。
- **小区→区县二级编码**：对小区缺失行回退到区县级中位（而非城市中位），
  缓解核心区/郊区价差问题（试点未见增益，需更多区县语料）。
- **接入更多真实成交价（网签/评估价）作标签**，降低挂牌价噪声。
